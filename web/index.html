See what a Windows binary asks Windows for

Drop an .exe or .dll and pe-import-lens reads its import table — the same parser as the CLI tool — flagging process-injection, hollowing, keylogging and anti-analysis imports.

The file is parsed in this tab only. It is never uploaded, executed or stored.

…or drag & drop the file here.

What gets flagged

  • High — VirtualAllocEx, WriteProcessMemory, CreateRemoteThread, NtUnmapViewOfSection (injection / hollowing primitives)
  • Medium — SetWindowsHookExA/W, GetAsyncKeyState (hooking / keylogging patterns)
  • Low — IsDebuggerPresent, CheckRemoteDebuggerPresent, VirtualProtect, ShellExecuteA/W

A flag is a review prompt, not a verdict — plenty of legitimate software imports these. For batch scans and JSON output, use the CLI from the GitHub repo.
